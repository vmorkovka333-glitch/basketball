# Handoff: Неон-Лига — 3D-игрок и система внешности (v4)

## Overview
Неон-Лига — самодостаточная браузерная 3D-игра в футбол (11×11) на three.js,
единый HTML-файл без сборки. Этот пакет описывает **модель игрока** и **систему
внешности** (кожа/волосы/борода/причёска), доработанные в v4 до вида, близкого к
FC Mobile: артикулированные капсульные тела, PBR-материалы, экипировка с кантом,
бутсы, а также узнаваемые реальные футболисты.

## About the Design Files
Файл `Неон-Лига v4.html` — это **не отдельный дизайн-макет для переноса в другой
фреймворк, а рабочая реализация**. Он открывается прямо в браузере и содержит всю
игру (three.js через importmap, весь игровой цикл, меню, магазин, карьеру). Задача
для разработчика — **дорабатывать этот файл напрямую** (или, при интеграции в
существующий движок, воспроизвести те же построители мешей и таблицы данных).
Здесь нет React/Vue: логика на ES-модуле + классический DOM.

## Fidelity
**High-fidelity / рабочий код.** Всё, что описано ниже, уже реализовано в файле и
проверено на приближённом рендере. Значения (радиусы капсул, позиции суставов,
roughness/metalness, hex-цвета) — итоговые.

## Технологии и запуск
- **three.js 0.160.0** через `<script type="importmap">` → `three.module.js`.
- **peerjs 1.5.4** (онлайн-матч, необязателен для рендера).
- Рендер: `WebGLRenderer({ antialias:true })`, `ACESFilmicToneMapping`,
  `toneMappingExposure = 1.16`.
- Освещение сцены: `HemisphereLight(0x8fb8ff,0x0a1428,0.85)` + 4 направленных
  (ключевой холодный, заполняющий, контровой сзади, тёплый спереди для кожи).
- Запуск: открыть HTML в браузере (нужен интернет для CDN three.js/peerjs).

## Модель игрока — структура (buildBody)
Игрок — это `THREE.Group` из простых примитивов, собранных в иерархию суставов,
чтобы `animatePlayer` вращал группы (не отдельные меши). Высота ≈ 1.77 ед.

Иерархия:
```
g (корень, position = игрок на поле)
├─ torso  (CapsuleGeometry(0.205,0.30), scale 1.06×1.0×0.60)  — джерси
├─ pelvis (CapsuleGeometry(0.165,0.10), scale 1.12×0.9×0.70)  — шорты
├─ neck   (CylinderGeometry)
├─ collar (TorusGeometry, материал trim)                      — ворот
├─ headG (position y=1.585)  ← ВРАЩАЕТСЯ (взгляд за мячом)
│   ├─ head (Sphere, scale 0.94×1.04×0.97)
│   ├─ 2× eye (белок) + 2× pupil
│   ├─ 2× brow (материал волос), nose, mouth
│   ├─ 2× ear
│   ├─ hairMeshes[]  ← buildHair(style)
│   └─ beardMeshes[] ← buildBeard(beard)
├─ hipL/hipR (Group)  ← вращение X (мах бедра)
│   ├─ legcuff (шорты), thigh (кожа, scale 1.06)
│   └─ kneeL/kneeR (Group)  ← вращение X (сгиб колена)
│       ├─ knee (Sphere), shin (гетра, scale 1.05)
│       ├─ sockband (Cylinder, trim)  — отворот гетры
│       └─ ankleL/ankleR (Group)  ← вращение X (голеностоп)
│           ├─ bootU (Capsule повёрнут, rotation.x=PI/2, scale 1×1.15×0.6) — глянцевый верх
│           └─ sole  (Box, матовый тёмный)                                  — подошва
└─ shL/shR (Group, position x=±0.232 y=1.39)  ← вращение X и Z (плечо)
    ├─ delt (Sphere, scale 0.86×1.14×0.86)  — дельта, сглаживает плечо
    ├─ uarm (рукав джерси)
    ├─ cuff (Torus, trim)  — кант рукава
    └─ elL/elR (Group)  ← вращение X (локоть)
        ├─ farm (кожа), hand (Sphere, scale 0.82×1.18×0.56 — «лопатка»)
```

### Материалы (все PBR через `pbr()`)
Приём: чтобы неоновые киты светились, а игроки не чернели на тёмном поле,
`emissive` = цвет материала с малым `emissiveIntensity`.
- `shirtM`  — kit,   `rough 0.55`, `ei 0.30`
- `shortsM` — shorts, `rough 0.66`, `ei 0.20`
- `sockM`   — sock,  `rough 0.78`, `ei 0.22`
- `skinM`   — skin,  `rough 0.62`, `ei 0.10` (+ `skinD` = кожа×0.82 для носа)
- `hairM`   — hair,  `rough 0.38`, `metal 0.05`
- `beardM`  — hair (тот же цвет), `rough 0.62`
- `bandM`   — `0x161616` (повязка)
- `bootM`   — boot,  `rough 0.24`, `metal 0.15` (глянец)
- `soleM`   — `0x0a0b0f`, `rough 0.9` (мат)
- `trimM`   — кант ворота/манжет/гетр. Цвет `trimCol` вычисляется автоматически:
  `lum(kit) > 0.6 ? dk(kit,0.42) : 0xeef2f8` (белый кант на тёмных/ярких китах,
  тёмный — на светлых).
- `handM`   — у вратаря белые перчатки `0xf2f5fa`, иначе `skinM`.

## Система внешности (главное в v4)
Каждому игроку по фамилии назначается внешность. Формат записи:
```js
'ФАМИЛИЯ': [skin, hair, style, beard]
```
- `skin` — из палитры `SK` (`lt,l,m,t,br,dk` — от светлой к тёмной).
- `hair` — из палитры `HR` (`blk,dbr,br,lbr,bl,bl2,gin,gry`).
- `style` — причёска (см. ниже).
- `beard` — `0` нет · `1` щетина · `2` борода (4-й элемент необязателен → 0).

### Причёски (buildHair(style))
```
0 короткие      4 длинные
1 с затылком    5 кудри/афро/локи
2 ирокез        6 короткий ёжик (buzz)
3 лысый         7 длинные + повязка (Холанд)
```

### Борода (buildBeard(beard))
Меш `GEO.beard` — сегмент сферы (полярный пояс нижней части лица, только фронт),
материал `beardM` (цвет волос). Щетина — плотнее к коже и ниже профилем; борода —
чуть крупнее. Пересобирается в `relook`.

### Резолвер
`lookFor(name)` возвращает `{skin,hair,style,beard}`. Если имени нет в
`PLAYER_LOOKS`, генерируется стабильно по хэшу имени (включая случайную
щетину/бороду — для разнообразия массовки).

### Применение
`mesh.relook({skin, hair, style, beard})` — меняет цвета материалов и
пересобирает волосы/бороду. Вызывается при выборе клуба/сборной:
см. `p.limbs.relook(lookFor(name))` в обработчиках старта матча
(лига/кубок/мир) и в `setOpponent`.

### Как добавить/поправить игрока
1. Добавить фамилию (ЗАГЛАВНЫМИ, как в составе) в `PLAYER_LOOKS`
   с массивом `[skin,hair,style,beard]`.
2. Убедиться, что та же фамилия есть в составе клуба (`CLUB_ROSTERS`)
   или сборной (`NATIONS[].sq`).
3. (Опц.) задать фирменное празднование в `CELEBS` (индекс стиля 0–16).

## Анимация (animatePlayer)
Каждый кадр задаёт углы: бёдра/колени/голеностоп (бег с волной, подъёмом корпуса
и переносом веса `rotZ`), плечи/локти в противофазе, отдельные позы для удара,
подката, вброса, прыжка головой, сейва вратаря и 17 празднований (`celebStyle`).
Голова (`headG`) плавно доворачивается на мяч.
