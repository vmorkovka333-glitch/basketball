# НЕОН-ЛИГА ⚡ 3D футбол 11×11 (V1.3)

Аркадный 3D-футбол на ночном неоновом стадионе. Команда НЕОН против ИИ-команды МАГМА:
два тайма, ауты и угловые, вратари с честными сэйвами, подкаты, адресные пасы, статистика матча.

**Играть онлайн: https://vmorkovka333-glitch.github.io/neon-liga/**

## Как запустить локально
Просто откройте `index.html` в браузере (нужен интернет — Three.js и шрифт грузятся с CDN).

## Управление (клавиатура)
- WASD / стрелки — движение, Shift — спринт
- X — удар (держать — сила), в защите — подкат
- Пробел — пас (летит тому, на кого показывает джойстик/взгляд), в защите — отбор
- C — навес, в защите (удержание) — прессинг
- Q — смена игрока, P — пауза

## Управление (телефон)
Слева — джойстик, справа — кнопки УДАР / ПАС / НАВЕС / СМЕНА / СПРИНТ.
В защите кнопки автоматически меняются на ПОДКАТ / ОТБОР / ПРЕССИНГ.

## Механика V1.3
- Точность ударов по дистанции: вблизи 98%, у штрафной 90%, издали 78%, с центра поля 60%
- Шанс сэйва вратаря зависит от времени полёта мяча: в упор почти не берёт, дальние тащит
- Оба вратаря используют одинаковую логику — никакого читерства ИИ
- Пас гарантированно доходит до адресата, если не перехвачен по пути
