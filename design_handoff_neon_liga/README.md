# Handoff: НЕОН-ЛИГА — 3D футбол (11×11)

## Overview
Аркадный 3D-футбол «НЕОН-ЛИГА»: матч 11 на 11 на ночном неоновом стадионе, игрок управляет командой НЕОН против ИИ-команды МАГМА. Полный игровой цикл: меню → матч из двух таймов → перерыв → финальный свисток со статистикой. Управление — клавиатура на десктопе и сенсорное управление в стиле мобильных футбольных игр (белый джойстик слева, кластер круглых кнопок в правом нижнем углу).

## About the Design Files
Файл в этом пакете — **работающий референс-прототип, созданный в HTML** (один файл, Three.js + Canvas + Web Audio). Это не production-код для прямого копирования. Задача — **пересобрать игру в целевой кодовой базе** с её паттернами: разбить на модули (сцена, физика, ИИ, ввод, UI/HUD), добавить сборку (Vite/esbuild), типизацию (TypeScript) и тесты. Если кодовой базы ещё нет — рекомендуемый стек: Vite + TypeScript + three (npm), UI-оверлеи можно оставить на DOM/CSS либо перенести в выбранный UI-фреймворк.

## Fidelity
**High-fidelity**: цвета, типографика, отступы, расположение кнопок, поведение камеры, физика и правила игры — финальные и должны быть воспроизведены точно. Прототип полностью играбелен: используйте его как эталон поведения.

## Interactions & Behavior

### Управление (десктоп)
- WASD/стрелки — движение; Shift — спринт (×1.32); Space — пас (в защите — выпад-отбор); X — удар, удержание заряжает силу 0→1 за 0.9с (в защите — подкат); C — навес (в защите удержание — прессинг: 3 партнёра прессингуют вместо 2); Q — смена игрока; P/Esc — пауза.

### Управление (touch)
Кнопки соответствуют клавишам; направление удара можно подруливать джойстиком; вибрация `navigator.vibrate`: удар 10мс, подкат 15мс, отбор 25мс, штанга 30мс, гол 80мс.

### Игровые правила и механика
- Поле 105×68м (полудлины HL=52.5, HW=34), ворота 7.32×2.44м. Гравитация аркадная G=16, мяч r=0.32 с трением качения 5.5 м/с², отскоком ×0.55 и сопротивлением воздуха 6%/с.
- Составы 4-4-2 (GK/DF/MF/FW с базовыми скоростями 6.8/7.2/7.5/7.7). Авто-переключение на ближайшего к мячу игрока (гистерезис 1.2м, кулдаун 0.4с).
- Удар: скорость 19+15×power; перезаряд (power>0.85) задирает траекторию. Пас — на лучшего адресата по скорингу (открытость, направление джойстика, перехват линии паса). Навес — по баллистике к дальнему форварду.
- Подкат: рывок ×2.25 на 0.5с, радиус отбора 1.4м; промах — оглушение 0.5с. Обычный выпад: ×1.9 на 0.35с, радиус 1.1м.
- Аут/угловой/от ворот — по последнему касанию; кикофф после гола — проигравшей командой; смена ворот во 2-м тайме. Игровые часы: тайм (2/3/5 мин реальных) отображается как 45 минут.
- ИИ: три пресета сложности (скорость 6.6/7.3/7.9; ошибки пасов 30/14/6%; ошибки ударов 35/18/8%; реакция вратаря 0.72/0.9/1.0; число прессингующих 1/2/2). Носитель мяча: решения каждые 0.55–0.95с — удар из зоны (<23м от ворот, |z|<17) при чистой линии, пас под давлением, вынос при опеке <1.4м, иначе дриблинг к воротам с уклонением. Вратарь: позиция на дуге 0.8–4.5м от линии, перехват прострелов, выход на свободный мяч <13м, вынос через 0.9с.
- Камера: следит за мячом (x×0.86, clamp ±44; высота 27+|z|×0.1; в портрете ×1.5 выше). Гол — наезд на ворота + фейерверк (4 залпа по 50 частиц) + вспышка света + всплеск толпы. Меню — орбита.
- Звук (Web Audio, без файлов): шум толпы (bandpass 550Гц) с всплесками на голах, свисток (1 — старт, 2 — перерыв, 3 — финал), удар по мячу, звон штанги.

## State Management
- Конечный автомат: `MENU → KICKOFF → PLAY ⇄ (RESTART | GOAL) → HALFTIME → PLAY → FULLTIME`, плюс `PAUSED` из любого игрового состояния (хранит prevState).
- Ключевые сущности: `ball {pos, vel, owner, lastKicker, kickT, lastTouchTeam}`; игрок `{pos, vel, target, yaw, role, chase, stunT, stealCd, lungeT, sliding, slideHit, loseT, decideCd}`; `teams[2] {score, dir, players, human}`; `stats {poss[2], shots[2]}`; `input {x, y, active, sprint}`, `chargeT`, `containHeld`, `controlled`.
- Таймеры: `matchT` (0→HALF_LEN на тайм), `stateT` (обратный отсчёт переходов: кикофф 1.4с, рестарт 1.2с, гол 2.8с, перерыв 2.6с).
